# Historical workstream policy

The rigid workstream and activation model is superseded by the current
[agent instructions](../../AGENTS.md). Use current GitHub issues and PRs to
understand the work and coordinate overlapping changes without overwriting
anyone's work. Past authorship and issue history remain unchanged.

establish a missing interface, or authorize operations.
